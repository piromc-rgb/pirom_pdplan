======================================================================
  CHAKEN Planing Pro - PD Plan
  คู่มือการติดตั้งโปรแกรมบนเครื่องคอมพิวเตอร์ใหม่ (How to Install)
======================================================================

โฟลเดอร์นี้รวบรวมไฟล์และคำแนะนำสำหรับการนำระบบไปติดตั้งบนคอมพิวเตอร์เครื่องใหม่
โดยสามารถทำตามขั้นตอนง่ายๆ เพียง 3 ขั้นตอนดังนี้ครับ:

----------------------------------------------------------------------
ขั้นตอนที่ 1: การคัดลอกโฟลเดอร์โปรเจกต์
----------------------------------------------------------------------
1. ก๊อปปี้โฟลเดอร์โปรเจกต์หลัก (pirom_pdplan-main) ไปวางไว้ที่เครื่องใหม่
   - สามารถวางไว้ที่ใดก็ได้ เช่น C:\CHAKEN_PDPlan หรือ D:\CHAKEN_PDPlan

----------------------------------------------------------------------
ขั้นตอนที่ 2: ดำเนินการติดตั้ง (เพียงคลิกเดียว)
----------------------------------------------------------------------
1. เปิดเข้าไปที่โฟลเดอร์ "How to install app"
2. ดับเบิ้ลคลิกไฟล์ "install.bat"
3. สคริปต์จะทำงานโดยอัตโนมัติ:
   - ตรวจสอบ Node.js และ npm (หากเครื่องใหม่ยังไม่มี จะติดตั้งให้อัตโนมัติ)
   - ติดตั้ง Dependencies ที่จำเป็นทั้งหมดของโปรแกรม
   - เตรียมไฟล์ฐานข้อมูลและคอนฟิกูเรชัน (Plan.json, completed_pds.json)
   - สร้างไอคอนชอร์ตคัต "CHAKEN PD Plan" ไว้ที่หน้าจอ Desktop ของเครื่องใหม่

----------------------------------------------------------------------
ขั้นตอนที่ 3: การเปิดใช้งาน
----------------------------------------------------------------------
หลังติดตั้งเสร็จ สามารถเปิดใช้งานได้ 2 วิธี:
วิธีที่ 1 (สะดวกที่สุด): ดับเบิ้ลคลิกไอคอน "CHAKEN PD Plan" บนหน้าจอ Desktop
วิธีที่ 2: ดับเบิ้ลคลิกไฟล์ "start_app.bat" ในโฟลเดอร์หลักของโปรแกรม

หมายเหตุ:
- โปรแกรมจะเปิดหน้าต่างเบราว์เซอร์ไปที่: http://localhost:5173/pirom_pdplan/
- ห้ามปิดหน้าต่างสีดำ (Command Prompt) ในขณะที่กำลังใช้งานโปรแกรม
- หากต้องการปิดโปรแกรม ให้ปิดเบราว์เซอร์และปิดหน้าต่าง Command Prompt ได้เลยครับ
